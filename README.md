# Victoria's 24Game

A free math puzzle game that runs in any web browser on a computer or phone. No install, no account, no ads.

**[Play it here](https://robbbrady.github.io/24Game/)**

## How to play

You get four numbers. Combine all four with + − × ÷, using each number once, to make exactly 24. Tap a number, tap an operator, then tap another number. The result replaces both, and you keep going until one number is left.

## Game modes

- **Classic:** Four numbers per card. Combine them to make 24.
- **Variables:** Two sets of three numbers share one unknown value (1-9). Find the value that makes 24 on both sets, then prove it by building 24 on each.
- **Negatives:** Classic play with whole numbers that can be negative.

Each mode has Easy, Medium, and Hard levels. Difficulty is based on how many different ways a card can reach 24. Fewer ways means a harder card.

## Features

- Unlimited cards, generated on the fly and always solvable
- Hints, undo, reset, skip, and show answer
- Timer, streaks, and best times saved in your browser (nothing is sent anywhere)
- Encouragement messages, sound, and confetti (sound can be turned off)
- Works offline once loaded

## Run it yourself

The whole game is one file. Download `index.html` and open it in a browser. On a phone, use the hosted link above, since phones often show downloaded HTML files as a static preview that doesn't run.
